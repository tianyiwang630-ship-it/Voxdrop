# MVP 实施记录

## 2026-09-11：M0/M1 纵切与 M2 数据能力

已实现：

- SwiftPM 原生菜单栏 App 骨架、稳定开发 Bundle ID 与麦克风用途说明。
- Hold/Toggle/Esc 会话状态机；交叉模式和晚到结果按 request ID/Worker generation 丢弃。
- AVAudioEngine 仅在显式触发后采集，并通过 AVAudioConverter 写入 16 kHz 单声道 WAV。
- 常驻 Python Worker 协议 v1、stdout 协议隔离、路径/消息/热词预算校验、结构化错误。
- NSPasteboard 标准输出、焦点变化/权限/修饰键/剪贴板竞争保护及单次 Cmd+V。
- SQLite 历史和热词持久化、分页查询、搜索、复制、单删和清空。
- 菜单栏、非激活 HUD、历史、设置、热词和诊断基础界面。
- 两组快捷键录制、冲突校验、独立持久化；120 秒录音/推理看门狗与三次有界 Worker 启动恢复。
- 构建并临时签名 `build/VoiceInput.app`，Info.plist 与签名校验通过。
- App 进程级 smoke 通过：菜单栏进程常驻且没有崩溃；系统权限未由自动化代替用户确认。
- `RuntimeLocator`/`ModelLocator` 与 `config/runtime-resources.json` 固化开发路径边界、Python/模型版本和校验摘要。
- 从 `/private/tmp`（非仓库工作目录）执行构建与 Swift 核心 smoke 通过，中文路径可解析。

自动测试：Python 10 项通过；Swift 主程序编译通过；无测试框架依赖的 Swift 核心 smoke（状态机、输出策略、SQLite 去重/删除）通过。Swift XCTest 测试已创建，但当前 Command Line Tools 不含 XCTest 模块，需完整 Xcode 执行。

真实模型 smoke：Qwen Worker 协议成功返回 `ready` 与结构化 `result`；`daily_zh_01.wav` 推理耗时 1506 ms。发现并修复当前 MLX 返回 language 数组的协议归一化问题。
