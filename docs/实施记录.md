# MVP 实施记录

## 2026-09-11：M0/M1 纵切与 M2 数据能力

已实现：

- SwiftPM 原生菜单栏 App 骨架、稳定开发 Bundle ID 与麦克风用途说明。
- Hold/Toggle/Esc 会话状态机；交叉模式和晚到结果按 request ID/Worker generation 丢弃。
- AVAudioEngine 仅在显式触发后采集，并通过 AVAudioConverter 写入 16 kHz 单声道 WAV。
- 常驻 Python Worker 协议 v1、stdout 协议隔离、路径/消息/热词预算校验、结构化错误。
- NSPasteboard 标准输出、权限/修饰键/剪贴板竞争保护及单次系统级 Cmd+V；发送时使用当前系统焦点。
- SQLite 历史和热词持久化、分页查询、搜索、复制、单删和清空。
- 菜单栏、非激活 HUD、历史、设置、热词和诊断基础界面。
- 两组快捷键录制、冲突校验、独立持久化；120 秒录音/推理看门狗与三次有界 Worker 启动恢复。
- 快捷键命中后捕获触发键的完整生命周期，不受修饰键与字符键的松开顺序影响；输出阶段同时等待修饰键和本次触发键松开，避免字符泄漏及残留修饰键破坏系统级粘贴。
- 构建并临时签名 `build/言落.app`，Info.plist 与签名校验通过。
- App 进程级 smoke 通过：菜单栏进程常驻且没有崩溃；系统权限未由自动化代替用户确认。
- `RuntimeLocator`/`ModelLocator` 与 `config/runtime-resources.json` 固化开发路径边界、Python/模型版本和校验摘要。
- 从 `/private/tmp`（非仓库工作目录）执行构建与 Swift 核心 smoke 通过，中文路径可解析。

自动测试：Python 11 项通过；Swift 主程序编译通过；无测试框架依赖的 Swift 核心 smoke（状态机、输出策略、SQLite 去重/删除、Bundle 配置、Worker 启停和启动错误）通过。Swift XCTest 测试已创建，但当前 Command Line Tools 不含 XCTest 模块，需完整 Xcode 执行。

真实模型 smoke：Qwen Worker 协议成功返回 `ready` 与结构化 `result`；`daily_zh_01.wav` 推理耗时 1506 ms。发现并修复当前 MLX 返回 language 数组的协议归一化问题。

尚未宣称通过：麦克风权限、非激活浮层、全局事件监听、Office/浏览器/Mail/微信真实粘贴、睡眠/设备切换和长时间运行。

## 2026-09-12：离线 DMG 发行链路

已实现：

- 发行 App 只从 Bundle 读取 CPython 3.11、MLX 依赖和 Qwen3-ASR 4-bit 模型，不读取项目目录，也不首次联网下载。
- Worker 使用隔离 Python、离线环境变量和包外会话目录；发行设置页隐藏开发项目路径。
- 统一 macOS 26.2 最低目标并限制 Apple Silicon；Info.plist 禁止多实例。
- 独立 runtime 组装、依赖许可证收集、资源摘要、Mach-O 架构/最低系统/动态链接检查和逐层 ad-hoc 签名脚本。
- 发行 App 约 1.145 GB；最终 ULFO DMG 为 710,724,230 字节，满足严格小于 1,000,000,000 字节的要求。
- 从只读 DMG 复制到随机临时目录并推出镜像后，使用复制品的包内 runtime/model 完成真实中文识别；结果正常，最终复验推理 1229 ms，推理后签名仍有效。

仍需外部人工验收：另一台 macOS 26.2+ M 系列 Mac、首次 Gatekeeper 放行、三项权限允许/拒绝/恢复、常用应用粘贴、睡眠唤醒和长时间运行。
