# macOS MVP 开发与启动

## 前置条件

- Apple Silicon Mac。
- 构建 App 可使用当前 Command Line Tools；运行 XCTest 测试需要带 XCTest 模块的完整 Xcode。
- 项目既有 Python 3.11 MLX 环境和本地 Qwen 模型已按 `环境搭建指引.md` 准备。

当前机器已经成功构建并临时签名开发 App。日常执行：

```bash
./scripts/run-macos-app.sh
```

脚本构建并临时签名 `build/言落.app`。首次启动后，在系统设置中为“言落”授予麦克风及辅助功能/输入监控权限。权限必须由 macOS 用户确认。

默认快捷键：

- Hold：`Control+Option+Space`，按住录音、松开提交。
- Toggle：`Control+Option+Command+Space`，首次开始、再次提交。
- `Esc`：取消当前录音或识别。

项目路径也可在设置页修改。App 不依赖启动时的当前工作目录；Python 以明确参数数组启动，不经过 shell。运行时不会执行 `uv sync` 或联网下载模型。

## 测试

```bash
.venv/bin/python -m pytest -q
./scripts/test-macos-core.sh
CLANG_MODULE_CACHE_PATH="$PWD/.cache/clang-module-cache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.cache/swiftpm-module-cache" \
swift test --disable-sandbox --package-path apps/macos
```

真实 Qwen smoke test 会占用较多统一内存，不属于默认单元测试。本次已通过产品 Worker 协议使用 `daily_zh_01.wav` 验证，推理约 1.5 秒。

## 数据与隐私

- 历史数据库：`~/Library/Application Support/com.local.VoxDrop/history.sqlite3`
- 临时音频：系统临时目录的 `com.local.VoxDrop/sessions/`，会话结束/取消后删除。
- App 不保存原始音频，不恢复旧剪贴板，不上传遥测。
- Worker stderr 只记录错误类别，不记录正文、热词全文或音频路径。

## 当前限制

- Swift 主程序已编译；当前 Command Line Tools 不含 XCTest/Testing 模块，Swift 测试须切换到完整 Xcode 后执行。
- 自动粘贴使用系统级 Cmd+V，发送时不锁定应用、窗口或输入框；各类应用仍须人工验收。发出事件只记为 `paste_attempted`，不代表目标应用已确认插入。
- 全局快捷键命中后会接管触发键从按下到松开的完整周期；即使先松开 Option/Control 等修饰键，触发键的重复事件和松开事件也不会泄漏成普通字符。粘贴前还会等待修饰键与本次触发键都实际松开，最长 500 ms；超时只保留剪贴板结果并提示手动粘贴。
- 已支持两组快捷键录制、冲突拦截和持久化；默认组合仍需结合用户日常软件实测冲突。
- 设备变化/睡眠恢复和长时间运行仍需实机验收。
- 不制作 DMG，不含模型下载器，不承诺无开发环境机器可运行。
